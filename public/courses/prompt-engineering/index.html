1.4 Context Windows & Tokens1.4 Tetingkap Konteks & Token

LLMs read text in "tokens" (roughly pieces of words). The "Context Window" is the maximum number of tokens it can hold in memory at once. Passing too much text causes the model to "forget" instructions at the beginning. LLM membaca teks dalam "token". "Tetingkap Konteks" ialah jumlah token maksimum yang boleh dipegang dalam ingatan serentak. Teks yang terlalu panjang menyebabkan model "lupa" arahan awal.

1.5 The Universal Prompt Anatomy1.5 Anatomi Prompt Universal

The most robust prompts always contain 5 elements: Role, Context, Task, Constraints, and Output Format. We will practice this deeply in later modules. Prompt paling teguh sentiasa mengandungi 5 elemen: Peranan, Konteks, Tugas, Kekangan, dan Format Output. Kita akan praktikkannya dalam modul seterusnya.

Istilah 'Zero-Shot' pada asalnya berasal dari penyelidikan penglihatan komputer, di mana model ditugaskan untuk mengenali objek yang tidak pernah dilihatnya sebelum ini!

Advanced Reasoning (CoT)Penaakulan Lanjutan (CoT)

If you force an immediate answer to a complex problem, LLMs guess. Chain-of-Thought (CoT) forces them to output their reasoning steps first. Here we explore variations of reasoning frameworks.

Jika anda memaksa jawapan segera untuk masalah kompleks, LLM meneka. Rantaian Pemikiran (CoT) memaksa mereka mengeluarkan langkah penaakulan dahulu. Di sini kita meneroka variasi rangka kerja penaakulan.

3.1 Zero-Shot & Emotional CoT3.1 CoT Zero-Shot & Emosi

Adding a simple phrase to trigger sequential processing. Combining it with emotional regulation improves logic (from the Prompt Cookbook). Menambah frasa mudah untuk mencetuskan pemprosesan berjujukan. Menggabungkannya dengan kawalan emosi meningkatkan logik.

Ex 1:Take a deep breath. Resolve this plot hole where the villain escapes step-by-step.Tarik nafas panjang. Selesaikan kelompangan plot ini selangkah demi selangkah.
Ex 1:Take a deep breath. Diagnose this NullReferenceException error step-by-step.Tarik nafas panjang. Diagnosis ralat NullReferenceException ini selangkah demi selangkah.

3.3 Step-Back Prompting3.3 Prompt Langkah Ke Belakang

Asking the model to abstract the question to a higher level of underlying principles before attempting to solve the specific instance. Meminta model untuk mengabstrakkan soalan kepada tahap prinsip asas yang lebih tinggi sebelum cuba menyelesaikan masalah khusus tersebut.

Ex 1:Before writing the climax, what are the central themes established in the hero's journey so far?Sebelum menulis klimaks, apakah tema utama yang ditubuhkan dalam perjalanan wira setakat ini?
Ex 1:Before debugging this React hook, explain the component lifecycle and state management principles.Sebelum menyahpepijat cangkuk React ini, terangkan kitaran hayat komponen dan prinsip pengurusan.

3.4 Least-to-Most Prompting3.4 Prompt Sedikit ke Paling Banyak

Decomposing a complex problem into a specific sequence of sub-problems and instructing the model to solve them sequentially. Menguraikan masalah yang kompleks kepada urutan sub-masalah tertentu dan mengarahkan model untuk menyelesaikannya secara berurutan.

Ex 1:First, list the variables. Next, identify the formula. Finally, solve the equation.Pertama, senaraikan pembolehubah. Seterusnya, kenal pasti formula. Akhir sekali, selesaikan persamaan.
Ex 1:First, summarize Q1 revenue. Next, summarize Q2 expenses. Finally, calculate the net delta.Pertama, ringkaskan hasil Q1. Seterusnya, ringkaskan perbelanjaan Q2. Akhir sekali, kira delta bersih.
Ex 1:First, outline the character's motivation. Next, describe the setting. Finally, write the scene.Pertama, gariskan motivasi watak. Seterusnya, terangkan latar. Akhir sekali, tulis adegan itu.
Ex 1:First, set up the database connection. Next, write the query. Finally, parse the JSON.Pertama, sediakan sambungan pangkalan data. Seterusnya, tulis pertanyaan. Akhir sekali, huraikan JSON.

3.5 Self-Consistency3.5 Konsistensi Kendiri

Asking the model to generate multiple distinct reasoning paths and take the majority vote as the final answer. Meminta model menjana beberapa laluan penaakulan yang berbeza dan mengambil undian majoriti sebagai jawapan akhir.

Constraints & FormattingKekangan & Format

Constraints define exactly what the model *should* do, and explicitly what it *should not* do. This lowers the cognitive load of editing the output later.

Kekangan menentukan dengan tepat apa yang model *perlu* buat, dan secara eksplisit apa yang *tidak patut* dilakukan.

Ex 1:The abstract summary must be exactly 3 sentences long and under 150 words.Ringkasan abstrak mestilah tepat 3 ayat panjangnya dan di bawah 150 patah perkataan.

4.3 Negative Constraints4.3 Kekangan Negatif

Telling the AI what to exclude. This is a common failure point for beginners. Memberitahu AI apa yang perlu dikecualikan. Ini adalah kegagalan biasa bagi pemula.

Ex 1:Do NOT include an introduction or conclusion. Do NOT use passive voice.JANGAN masukkan pengenalan atau kesimpulan. JANGAN guna ayat pasif.
Ex 2:Never invent citations. Only use the references provided in the text.Jangan sekali-kali mencipta petikan. Hanya gunakan rujukan yang diberikan.
Ex 1:Never use corporate jargon like 'synergy' or 'bandwidth'.Jangan sesekali gunakan jargon korporat seperti 'sinergi'.
Ex 2:Do not include conversational filler (e.g., 'Sure, here is the text').Jangan sertakan pengisi perbualan (cth., 'Pasti, ini teksnya').
Ex 1:Do NOT use adverbs. Do NOT use the word 'suddenly'.JANGAN gunakan kata keterangan. JANGAN gunakan perkataan 'tiba-tiba'.
Ex 2:Never use fantasy cliches like chosen ones or ancient prophecies.Jangan guna klise fantasi seperti orang yang terpilih.
Ex 1:Never use the 'eval()' function. Do not import third-party packages.Jangan sekali-kali gunakan fungsi 'eval()'. Jangan import pakej pihak ketiga.
Ex 2:Do not output any explanation. Output ONLY the raw code.Jangan berikan sebarang penjelasan. Hanya hasilkan kod mentah sahaja.

4.4 Output Syntax (JSON, Markdown, XML)4.4 Sintaks Output (JSON, Markdown, XML)

Forcing the LLM into a syntax makes it easier for other software to consume the output automatically. Memaksa LLM ke dalam sintaks menjadikannya lebih mudah bagi perisian lain untuk memproses output secara automatik.

4.5 LPML (LLM Prompting Markup Language)4.5 LPML (Bahasa Penanda Prompting LLM)

Using XML-like tags (e.g., <THINK>, <OUTPUT>) inside your prompt to strictly section the AI's internal scratchpad from its final deliverable. Menggunakan tag seperti XML (cth., <THINK>) di dalam prompt anda untuk memisahkan pad conteng dalaman AI dengan hasil akhirnya secara tegas.

Ex 1:Put your reasoning inside <THINK> tags, and the final equation inside <MATH> tags.Letakkan alasan anda di dalam tag <THINK>, dan persamaan akhir di dalam tag <MATH>.

Iteration & Meta-PromptingLelaran & Meta-Prompting

Robust LLM workflows rely on iterative pipelines rather than single prompts. This includes safety hatches, chaining, reflection, and using the LLM to orchestrate itself.

Aliran kerja LLM yang mantap bergantung kepada saluran berulang. Ini termasuk "jalan keluar" keselamatan, rantaian, refleksi, dan menggunakan LLM untuk menyusun dirinya sendiri.

5.1 The Escape Hatch5.1 Jalan Keluar Selamat

Giving the AI explicit permission to fail safely to prevent hallucinations.Memberi AI kebenaran eksplisit untuk gagal dengan selamat demi mencegah halusinasi.

Ex: If the research paper does not explicitly state the sample size, output ONLY 'N/A'.Jika kajian tidak menyatakan saiz sampel secara jelas, keluarkan HANYA 'N/A'.
Ex: If the client's email does not contain an invoice number, reply strictly with 'Missing'.Jika e-mel pelanggan tidak mengandungi nombor invois, balas tegas dengan 'Tiada'.
Ex: If the requested genre mix is incompatible, output ONLY 'Genre Clash'.Jika campuran genre tidak serasi, hanya keluarkan 'Pertembungan Genre'.
Ex: If the code snippet contains a vulnerability, output strictly 'VULNERABLE'.Jika kod mempunyai kelemahan keselamatan, keluarkan 'TERdedah'.

5.2 Prompt Chaining5.2 Rantaian Prompt

Breaking complex tasks into a sequence of smaller prompts.Memecahkan tugas yang kompleks kepada urutan prompt yang lebih kecil.

Ex: Step 1: "Extract claims." -> Step 2: "Fact-check claims."Langkah 1: "Keluarkan dakwaan." -> Langkah 2: "Semak fakta dakwaan."
Ex: Step 1: "Analyze tone." -> Step 2: "Draft response based on tone."Langkah 1: "Analisis nada." -> Langkah 2: "Rangka respons berdasarkan nada."
Ex: Step 1: "Outline the plot." -> Step 2: "Write Chapter 1 based on outline."Langkah 1: "Rangka plot." -> Langkah 2: "Tulis Bab 1 berdasarkan rangka."
Ex: Step 1: "Write unit tests." -> Step 2: "Write code to pass the tests."Langkah 1: "Tulis ujian unit." -> Langkah 2: "Tulis kod untuk melepasi ujian."

5.3 Reflexion5.3 Refleksi

Asking the model to evaluate its own previous output before finalizing.Meminta model untuk menilai output sebelumnya sebelum dimuktamadkan.

Ex: Review your previous critique. Are there biases? Revise if necessary.Semak semula kritikan anda. Adakah terdapat berat sebelah? Semak semula.
Ex: Review the copy. Does it meet the constraint of avoiding jargon? Rewrite.Semak teks. Adakah ia memenuhi kekangan mengelak jargon? Tulis semula.
Ex: Read your dialogue. Do all characters sound the same? Make voice A more gruff.Baca dialog anda. Adakah semua berbunyi sama? Jadikan suara A lebih kasar.
Ex: Review your SQL query. Does it handle SQL injection risks? Fix it.Semak pertanyaan SQL anda. Adakah ia mengendalikan risiko suntikan SQL?

5.4 Meta-Prompting5.4 Meta-Prompting

Transforming the LLM into a multi-faceted conductor that creates and manages specialized "expert" sub-instances.Mengubah LLM kepada konduktor pelbagai rupa yang mencipta "pakar" sub-contoh.

Ex: You are the conductor. Ask Expert 1 to review literature, Expert 2 to check methods, and synthesize their findings.Anda konduktor. Minta Pakar 1 semak literatur, Pakar 2 semak kaedah, dan sintesiskan penemuan.
Ex: Ask the Legal agent to check compliance, the PR agent to check tone, and combine into a final press release.Minta ejen Undang-undang semak pematuhan, ejen PR semak nada, dan gabungkan jadi siaran akhbar.
Ex: Have the Dialogue expert and the World-Building expert review the scene and merge their edits.Minta pakar Dialog dan pakar Pembinaan Dunia menyemak adegan dan menggabungkan suntingan mereka.
Ex: Ask the Security agent and the Performance agent to review the code, then output the synthesized code.Minta Ejen Keselamatan dan Ejen Prestasi menyemak kod, kemudian hasilkan kod sintesis.

Cognitive TopologiesTopologi Kognitif

Prompting is evolving beyond simple inputs into complex "topologies"—structural networks of reasoning. We explore advanced frameworks that orchestrate AI intelligence.

Prompting kini berkembang melangkaui input mudah kepada "topologi" kompleks—rangkaian penaakulan berstruktur. Kita meneroka kerangka canggih yang menyusun kecerdasan AI.

6.1 Tree of Thoughts (ToT)6.1 Pokok Pemikiran (ToT)

Generalizes CoT by generating multiple lines of reasoning in parallel as a decision tree, allowing the model to evaluate states, backtrack, or explore different branches. Mengembangkan CoT dengan menghasilkan pelbagai laluan penaakulan secara selari sebagai pepokok keputusan, membolehkan model menilai, berundur, atau meneroka cabang berbeza.

Ex: Brainstorm 3 distinct approaches to solve this problem. Evaluate pros and cons of each, then select the best.Sumbangsaran 3 pendekatan berbeza untuk menyelesaikan masalah ini. Nilai kebaikan dan keburukan setiap satu.
Ex: Generate 3 distinct marketing angles. Evaluate the cost-to-acquisition for each. Proceed with the cheapest.Hasilkan 3 sudut pemasaran. Nilai kos kepada pemerolehan. Teruskan dengan yang paling murah.
Ex: Write 3 different ending scenarios. Evaluate the emotional impact of each. Develop the most tragic one.Tulis 3 senario penamat. Nilai kesan emosi setiap satu. Kembangkan yang paling tragis.
Ex: Propose 3 different DB architectures. Evaluate the query latency for each. Output the fastest one.Cadangkan 3 senibina DB berbeza. Nilaikan kependaman pertanyaan untuk setiap satu. Hasil yang terpantas.

6.2 ReAct (Reason & Act)6.2 ReAct (Taakul & Bertindak)

Synergizes reasoning and acting by prompting the LLM to generate reasoning traces and task-specific actions (e.g., search or tool use) in an interleaved loop. Mensinergikan penaakulan dan tindakan dengan menggesa LLM untuk menghasilkan jejak penaakulan dan tindakan khusus tugas secara berselang-seli.

Loop Example:Contoh Kitaran:Thought: I need to find out the current CEO of Apple. Action: Search[Apple CEO] Observation: Tim Cook is the CEO of Apple. Thought: Now I need to find his age. Action: Search[Tim Cook age]...Fikir: Saya perlu cari CEO Apple terkini. Tindakan: Cari[CEO Apple] Pemerhatian: Tim Cook ialah CEO Apple. Fikir: Sekarang saya perlu cari umurnya. Tindakan: Cari[umur Tim Cook]...

6.3 Graph of Thoughts (GoT)6.3 Graf Pemikiran (GoT)

Models information as a graph where arbitrary thoughts can merge (synergize) and branch, mimicking complex human problem-solving networks. Memodelkan maklumat sebagai graf di mana pemikiran boleh bergabung (bersinergi) dan bercabang, meniru rangkaian penyelesaian masalah manusia yang kompleks.

Example:Contoh: "Generate 4 independent concepts. Merge concept 1 and 3 into a new idea. Merge concept 2 and 4 into another. Then evaluate which merged idea is stronger." "Jana 4 konsep bebas. Gabungkan konsep 1 dan 3 ke dalam idea baru. Gabung konsep 2 dan 4. Kemudian nilai idea gabungan mana yang lebih kukuh."

6.4 LLM as an Evaluator6.4 LLM sebagai Penilai

Using a separate LLM prompt to grade, evaluate, or score the output of another prompt based on a specific rubric. Menggunakan prompt LLM yang berasingan untuk menggred, menilai atau menskor output prompt lain berdasarkan rubrik tertentu.

6.5 Cumulative Reasoning6.5 Penaakulan Kumulatif

Storing verified facts in a persistent memory structure during a multi-turn prompt so the LLM doesn't forget foundational logic steps. Menyimpan fakta yang disahkan dalam struktur memori berterusan supaya LLM tidak melupakan langkah logik asas.

Specialized FrameworksRangka Kerja Khusus

This final module explores highly specialized techniques required for enterprise-grade LLM applications, including grounding, stimulus guidance, and ethical debiasing.

Modul terakhir ini meneroka teknik khusus yang diperlukan untuk aplikasi LLM gred perusahaan, termasuk rujukan berlandaskan fakta, panduan stimulus, dan penyahbiaran etika.

7.1 Chain of Reference (CoR)7.1 Rantaian Rujukan (CoR)

CoR grounds the LLM by forcing it to reference a specific framework (e.g., Legal IRAC) before concluding. CoR memaksanya untuk merujuk rangka kerja tertentu sebelum menyimpulkan.

CoR Ex: Break down the input into a Chain of References: Issue, Rule, Application, Conclusion.Cerakinkan input kepada Rantaian Rujukan: Isu, Peraturan, Aplikasi, Kesimpulan.
CoR Ex: Break down the decision into a Chain of References: Market Risk, Financial Risk, Operational Risk.Cerakinkan keputusan kepada Rantaian Rujukan: Risiko Pasaran, Kewangan, Operasi.
CoR Ex: Reference the provided Lore Bible text specifically before deciding how the character reacts.Rujuk teks Lore Bible yang diberikan secara khusus sebelum memutuskan cara watak bertindak.
CoR Ex: Reference the ISO 27001 compliance framework before approving this architecture design.Rujuk rangka kerja pematuhan ISO 27001 sebelum meluluskan reka bentuk seni bina ini.

7.2 Directional Stimulus Prompting7.2 Prompt Stimulus Berarah

Providing small, specific hints or keywords (stimuli) to guide the LLM's generation toward a desired outcome without writing the whole sentence for it. Menyediakan petunjuk atau kata kunci khusus (stimulus) untuk membimbing penjanaan LLM ke arah hasil yang diingini.

Example:Contoh:Article: [Text about climate change] Write a short summary. Hint: Focus on "carbon taxes" and "renewable subsidies".Artikel: [Teks tentang perubahan iklim] Tulis ringkasan pendek. Petunjuk: Fokus pada "cukai karbon" dan "subsidi boleh diperbaharui".

7.3 Causality-Guided Debiasing7.3 Penyahbiaran Berpandukan Kausaliti

Explicitly instructing the model to ignore demographic identifiers (gender, race, age) to counteract inherent selection bias in the LLM's training data. Mengarahkan model secara eksplisit untuk mengabaikan pengecam demografi (jantina, bangsa, umur) untuk menentang kecenderungan yang wujud dalam data latihan LLM.

Example:Contoh:Evaluate this resume for a nursing position. Assume the candidate can be either male or female. Do not use gender stereotypes.Nilaikan resume ini. Andaikan calon boleh menjadi lelaki atau perempuan. Jangan gunakan stereotaip jantina.

7.4 Automatic Prompt Optimization (APO)7.4 Pengoptimuman Prompt Automatik

Using an LLM to analyze the failure points of a previous prompt and automatically generate a better version of that prompt. Menggunakan LLM untuk menganalisis titik kegagalan prompt sebelumnya dan menjana versi yang lebih baik secara automatik.

7.5 RAG Prompting Integration7.5 Integrasi Prompt RAG

Retrieval-Augmented Generation relies on a prompt that strictly instructs the model to ONLY answer based on the injected, retrieved text. Prompt RAG dengan tegas mengarahkan model untuk HANYA menjawab berdasarkan teks yang dimasukkan.
