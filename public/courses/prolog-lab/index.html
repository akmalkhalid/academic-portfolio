How to use PROLOG//LAB

  
Follow the steps on the left. Edit the program, ask queries in the console, and watch the search tree to see how Prolog thinks. Tasks are checked instantly.

  

    
EnterRun the query in the console

    
;  or  NextAsk for the next answer (backtrack)

    
Enter  or  .Stop looking for more answers

    
↑ / ↓Query history

    
Ctrl + SConsult (check & load) the program

    
Ctrl + EnterJump from editor to console

    
EscAbort a running query

    
Click a tree nodeHighlight the clause that proved it

  

  
Like SWISH, each query runs against a fresh copy of the program in the editor. Things you assert during a query do not carry over to the next query.
