Why local?

Why run AI on your own laptop

Your data stays here

Student records and unpublished manuscripts never leave your machine.

No usage bills

After a one-time model download, every prompt is free and unlimited.

Works offline

In a seminar room with weak Wi‑Fi, or on the road between campuses.

The trade-off: local models are smaller than cloud chatbots. Great for drafting, sorting and summarising. Always check facts.

Sources: Personal Data Protection Act 2010 (Act 709), pdp.gov.my · Elsevier, “Generative AI in the review process”, elsevier.com/about/policies-and-standards

Key idea

Three levels of AI help

LEVEL 1

Chatbot

You ask, it answers. “Draft a reminder email.”

LEVEL 2

Agent

You give a goal. It plans, uses tools (files, terminal, web) and checks its work.

“Update the register from these 30 CSV files.”

LEVEL 3

Workflow automation

A trigger fires (a time, an email). The agent runs the steps. You review.

“Every Friday 5 pm, tally RSVPs and email the organiser.”

After: Anthropic (2024), “Building effective agents”, anthropic.com/engineering/building-effective-agents

02 · Key idea

An agent works in a loop

You give a goal. The model thinks, picks a tool, reads the result, and repeats until done.

A chatbot stops after one reply. An agent keeps going.

Known in research as ReAct: reasoning and acting, interleaved.

Yao, S. et al. (2023). ReAct: Synergizing reasoning and acting in language models. ICLR. doi.org/10.48550/arXiv.2210.03629

02 · Before your first task

No 64K, no tools

Hermes's instructions and tool list take about 13K tokens. Ollama often runs a local model at 4K, so the instructions get cut off and every tool call fails, whatever the model.

LOCAL MODEL · make a 64K copy once

Save a text file named Modelfile with two lines:

FROM qwen3.5:9b
PARAMETER num_ctx 65536

ollama create qwen3.5-64k -f Modelfile

Then hermes model → choose qwen3.5-64k

Cloud model? Run ollama signin once. Cloud models already use their full window.

Case study 2 · You are the reviewer

Check the policy first, then choose a lane

LANE A · JOURNAL ALLOWS AI ASSISTANCE

“Run tools/review_by_section.py on reviews/manuscript_042.pdf. Then read outputs/review_manuscript_042/02_draft_report.md and list the five most serious concerns.”

The tool reads it section by section. Then verify every point against the paper and rewrite in your own voice.

LANE B · JOURNAL FORBIDS IT (e.g. Elsevier)

“Turn my notes in reviews/my_notes.txt into the journal’s report template. Fix grammar only. Do not add new points.”

The agent never sees the manuscript. The judgement is entirely yours.

Sources: Elsevier, “The use of generative AI … in the review process” (elsevier.com) · COPE position statement, publicationethics.org · PDF tool needs: pip install pypdf (or use the .txt copy)

Case study 2 · Set expectations

What a laptop model can review

GOOD AT, ONE SECTION AT A TIME

Missing method details and unclear writing

Numbers that disagree between sections

Citations missing from the reference list (done by code)

Thesis: does each objective get answered?

Drafting viva questions and response tables

NOT RELIABLE: STAYS YOUR JOB

Judging novelty against the latest literature

Checking statistics or reproducing results

Reading charts and images in the PDF (text only)

Whole-thesis judgement in a single pass

The accept / reject or pass / fail decision

A thesis becomes 20–40 parts, so expect a long run on a laptop: start it before lunch, or schedule it overnight with hermes cron.

03 · Key idea

Fixed workflow or flexible agent?

WORKFLOW
same steps every time

Friday 5 pm

Read RSVPs

Tally

Draft email

You review

AGENT
chooses its own steps

Goal: “Find out why RSVPs dropped this week.” It decides what to open, compare and ask.

TRIGGER: A TIME

Every Friday 5 pm → scheduled task

TRIGGER: A MESSAGE

New email in the event inbox → gateway

TRIGGER: A FILE

New RSVP file → picked up by an hourly check

Workflow vs agent distinction after Anthropic (2024), “Building effective agents”, anthropic.com/engineering/building-effective-agents

Before you go live

Six habits for responsible use

Verify

It can be confidently wrong. Check names, numbers, citations.

Stay in the loop

You approve, sign and own every output.

Protect personal data

Least data needed, stored securely, as PDPA 2010 expects.

Follow policy

Journal, university and funder rules. Disclose AI use.

Back up first

Copy files before any edit. Hermes can also roll back.

Keep it updated

Run hermes update for security fixes.

If something goes wrong

What you seeTry this
“ollama” or “hermes” not recognizedClose the terminal, open a new one. Still stuck? Restart the laptop
Answers are very slowUse a smaller model. Run ollama ps: 100% GPU is best
Hermes cannot reach the modelIs Ollama running? URL must be http://127.0.0.1:11434/v1
